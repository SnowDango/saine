現在のブランチから `$ARGUMENTS` ブランチ（省略時は `develop`）向けの PR を作成するスキルです。PR の概要はリポジトリのプルリクエストテンプレートを元に生成します。

## 引数

`$ARGUMENTS` にベースブランチ名を指定できます。
- 省略時: `develop` をベースブランチとして使用

## 手順

以下の手順を順番に実行してください。

### 1. 現在の状態を確認

```bash
git status
git branch --show-current
git log <ベースブランチ>..HEAD --oneline
git diff <ベースブランチ>...HEAD --stat
```

### 2. PR テンプレートを読み込む

`.github/pull_request_template.md` を Read ツールで読み込んでください。

### 3. 差分を分析してタイトルと本文を生成

`git diff <ベースブランチ>...HEAD` の内容を確認し、変更の種類・目的・影響範囲を把握したうえで、以下のルールに従い PR のタイトルと本文を生成してください。

**タイトルのルール:**
- Conventional Commits 形式（`feat:` / `fix:` / `chore:` / `refactor:` など）
- 70文字以内
- 日本語でも英語でも可（リポジトリの既存コミットスタイルに合わせる）

**本文のルール:**
- `.github/pull_request_template.md` の構造をそのまま使う
- `## 概要` セクション: 何を・なぜ変更したかを箇条書きで記述
- `## 変更内容` セクション: 変更の種類のチェックボックスを差分に基づいて適切にチェック（`- [x]`）
- `## 動作確認` セクション: 変更内容に関係するチェック項目は残し、無関係なものもそのまま残す（ユーザーが手動確認するため）
- `## スクリーンショット` セクション: UI 変更がある場合はその旨を記載、なければ「なし」と記載
- `## 関連 Issue` セクション: 不明な場合は空のまま残す
- 末尾に `🤖 Generated with [Claude Code](https://claude.com/claude-code)` を追加

### 4. 未コミットの変更がある場合

`git status` でステージされていない変更や未追跡ファイル（`.claude/`・`.idea/` などの IDE ファイルを除く）がある場合は、ユーザーに確認してからコミットしてください。

### 5. PR を作成

```bash
gh pr create \
  --base <ベースブランチ> \
  --title "<生成したタイトル>" \
  --body "$(cat <<'EOF'
<生成した本文>
EOF
)"
```

### 6. PR の URL をユーザーに報告

作成した PR の URL を表示してください。
